# rustgrid-agent v1.4.55

This patch release prevents distinct repository mutation attempts within one
ValidationRepair target from receiving the same failure identity.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Fixed

- Derive mutation failure identity from the active graph node's deterministic
  attempt ordinal rather than only the fallback budget counter.
- Distinguish an initial repair mutation attempt from its bounded fallback while
  retaining stable identity for an exact replay of either attempt.
- Preserve the original failure record and strict duplicate-event protection.
- Allow a successful `replace_file` fallback response to continue into normal
  repository mutation application without colliding with the earlier
  `apply_patch` failure.

## Regression coverage

- Prove one ValidationRepair target records distinct deterministic identities
  for attempt 1 and fallback attempt 2.
- Prove exact replay reconstructs the same logical failure without producing an
  additional identity.
- Keep the same-target ValidationRepair fallback, restricted provider payload,
  failed-validation continuation, normal mutation fallback, and hosted
  pull-request golden-path regressions green.

## Compatibility

No validation execution, failure parsing, repair ranking, fallback selection,
provider tool filtering, repair budget, graph architecture, publication, or
terminal behavior changes in this release.
