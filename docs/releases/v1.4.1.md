# rustgrid-agent v1.4.1

This hotfix corrects the production control-plane origin used by ephemeral
GitHub Actions execution.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Fixed

- Hosted execution now derives its default from the same
  `https://app.rustgrid.com` control-plane origin as persistent workers.
- The GitHub OIDC exchange therefore targets
  `https://app.rustgrid.com/api/v1/execution-auth/github-actions/exchange`
  instead of the retired `api.rustgrid.com` hostname.
- Explicit `RUSTGRID_API_URL` overrides remain supported and continue to
  normalize an origin or `/api/v1` root without duplicating the API prefix.

## Deployment status

Upgrade canonical GitHub Actions workflows to `v1.4.1` before retrying failed
hosted executions. The failed v1.4.0 attempt did not complete its OIDC exchange
and therefore did not receive a RustGrid execution token.

Artifact publication is not production deployment approval. Complete staging
certification against the exact `v1.4.1` image digest before deploying it.

## Rollback

If rollback is required, stop hosted dispatches and return to `v1.4.0`.
Ephemeral GitHub Actions execution in v1.4.0 requires an explicit
`RUSTGRID_API_URL=https://app.rustgrid.com` override; do not retry it with the
broken default. Do not replace or mutate existing tags or release assets.
