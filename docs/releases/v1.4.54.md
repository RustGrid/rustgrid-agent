# rustgrid-agent v1.4.54

This patch release lets a validation repair use the existing bounded repository
mutation fallback before abandoning its selected repair target.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Fixed

- Preserve the active `ValidationRepair` node and selected repository target
  after a recoverable repair mutation failure such as a patch-context mismatch.
- Restart that repair node through the existing bounded mutation-attempt
  lifecycle and derive its fallback from the typed repository mutation failure.
- Restrict a forced replacement fallback at the serialized provider boundary so
  the repair request exposes and forces only `replace_file`.
- Continue successful fallback repair through repository verification, repair
  completion, and the originating validation rerun.
- Preserve the existing behavior where an explicit no-valid-repair result
  advances to the next evidence-ranked candidate.

## Regression coverage

- Prove a failed validation selects a generic repair target, rejects its initial
  patch, retains the same repair node and target, and serializes a
  `replace_file`-only fallback request.
- Prove the successful fallback completes the repair and schedules the existing
  validation rerun.
- Prove an explicit no-valid-repair result still advances to another eligible
  candidate.
- Keep the hosted pull-request golden path, normal mutation fallback, and failed
  validation continuation regressions green.

## Compatibility

No discovery, planning, validation parsing, repair ranking, publication,
terminal handling, budget, graph architecture, or lifecycle guardrail behavior
changes in this release.

## Rollback
