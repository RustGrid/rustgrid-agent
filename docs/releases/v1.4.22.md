# rustgrid-agent v1.4.22

This patch release fixes hosted startup classification so a clean new mission
begins discovery instead of entering the recovery-publication path.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Changed

- Resolve hosted startup into one of three explicit modes: fresh execution,
  resume from the next persisted graph node, or recovery-publication evaluation.
- Base the decision on a schema-compatible notebook, persisted graph state,
  explicit recovery markers, and the checked-out repository diff.
- Emit structured startup and recovery decision events with notebook revision,
  graph presence, branch state, and the selected next action.

## Fixed

- Do not interpret the normal manifest branch on a clean fresh checkout as
  evidence that publication recovery is required.
- Initialize and persist the canonical execution snapshot before discovery on a
  fresh mission.
- Resume compatible persisted graphs at their next node without routing them
  through publication recovery.
- Evaluate recovery publication only for an interrupted publication or
  recoverable orchestration failure with repository changes.
- Treat recovery publication with no remaining diff as a successful no-op.
- Preserve startup and graph-initialization failures under their actual
  categories, and never report an AI gateway failure when no provider request
  was attempted.

## Compatibility, security, and known limitations

Existing manifest, notebook schema, execution-graph, API, credential, and
repository-permission contracts remain unchanged. Persisted notebooks are used
only when their schema, base SHA, and branch match the current manifest. This
release adds no credential scope, repository permission, or network access.

Artifact publication updates the GitHub release, native binaries, Homebrew
formula, SBOM, attestations, and container. It does not deploy a production
worker. Production must be updated separately to the exact v1.4.22 Linux
archive URL and SHA-256 after the protected release workflow completes.

## Verification

The complete locked Rust suite, API-contract suite, CLI suite, npm quality gate,
release build, package verification, formatting, strict Clippy, and diff checks
must pass for this release candidate. Focused startup regressions cover clean
fresh execution, discovery initialization, persisted-graph resume, interrupted
publication recovery, no-diff recovery, provider-free failure classification,
and preservation of the original startup error.

## Rollback

Stop new hosted dispatches before restoring the RustGrid worker download URL
and SHA, canonical workflows, and Homebrew installations to v1.4.21. Do not
replace or mutate the v1.4.22 tag or release assets. Persisted graph checkpoints
and notebooks remain compatible with v1.4.21.
