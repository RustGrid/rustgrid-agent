# rustgrid-agent v1.4.0

This feature release adds secure ephemeral mission execution on GitHub-hosted
runners and refreshes the agent's Rust, GitHub Actions, and container runtime
dependencies.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## GitHub Actions hosted execution

- Run one RustGrid mission on a disposable GitHub-hosted runner with
  `rustgrid-agent execute --provider github-actions`.
- Exchange GitHub OIDC identity and a one-time dispatch nonce for a short-lived,
  execution-bound RustGrid credential. OpenAI credentials remain server-side.
- Use the bounded RustGrid Responses adapter, deterministic branch recovery,
  worker-owned quality gates, short-lived GitHub App publication credentials,
  and idempotent completion.
- Report emergency startup failures through the same authenticated OIDC
  boundary rather than accepting an unauthenticated callback.

## Isolation and supply chain

- Run repository-controlled hosted commands in root-owned cgroup-v2 leaves.
  The coordinator attaches each blocked child through a bounded privileged
  write, verifies its membership before release, sets `no_new_privs`, and kills
  every descendant before requesting publication credentials.
- Keep hosted child environments free of RustGrid, GitHub Actions, GitHub,
  OpenAI, and ChatGPT credentials, and fail closed on unsupported or escapable
  runner configurations.
- Upgrade all open Dependabot suggestions: `anyhow`, `base64`, `clap`, `libc`,
  `serde`, `serde_json`, `sha2`, `uuid`, and `actions/checkout`.
- Patch npm's embedded `brace-expansion` and `tar` packages so the release
  container has no fixable High or Critical vulnerability findings.

## Deployment status

Artifact publication is not production deployment approval. Complete staging
certification against the exact `v1.4.0` image digest before deploying it.

See [GitHub Actions hosted execution](https://github.com/RustGrid/rustgrid-agent/blob/v1.4.0/docs/github-actions-execution.md),

## Rollback

Drain active work, stop the worker or hosted dispatch, reinstall `v1.3.0`, and
restart or redispatch with valid authentication. Do not replace or mutate
existing tags or release assets; publish further fixes under a new semantic
version.
