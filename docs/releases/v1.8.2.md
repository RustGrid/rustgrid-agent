# rustgrid-agent v1.8.2

This patch release makes `/rustgrid-link` work in VS Code when a file is open
in the editor.

## Install or upgrade

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

Restart Claude Code after upgrading. There is no need to run
`rustgrid-agent trace install` again.

## Fixed

- **`/rustgrid-link KEY` links the session when a file is open in VS Code.**
  The Claude Code extension adds a note about the open file or selected lines
  to the prompt, such as `<ide_opened_file>…</ide_opened_file>`. The hook only
  recognised `/rustgrid-link KEY` as the whole prompt, so with a file open it
  let the prompt through without linking. The session stayed unlinked, or on
  the ticket its branch or an earlier link gave it. The command then told
  Claude that a missing link meant tracing was not installed, so re-running
  `trace install` looked like the fix. The hook now sets IDE notes aside
  before reading the command.
- `/rustgrid-link` with no readable ticket key is refused with a usage hint
  instead of passing through as a normal prompt.
- When a link does not happen, Claude now says so and points to
  `rustgrid-agent trace status` instead of claiming tracing is not installed.
  The updated command reaches each person's `~/.claude/commands` the next time
  a session starts.

## Compatibility

- Works with the same RustGrid as v1.8.1. Session state written by v1.8.1 or
  v1.8.0 is read as is. Installed hooks are unchanged.
