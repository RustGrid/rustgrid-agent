# rustgrid-agent v1.6.4

This patch release closes an IDE session's run when the person starts a new
conversation, so the ticket gets its summary and the run's timer stops.

## Install or upgrade

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

Restart Claude Code after upgrading.

## Fixed

- **New conversation closes the old run.** The IDE's **+** button starts a
  new session without Claude Code reporting that the previous one ended. Its
  run stayed open, with the timer running, until RustGrid's two-hour idle rule
  closed it. When a session starts, a session in the same folder that has had
  no turn running for 30 seconds is now ended: its last reply is uploaded, its
  run closes, and RustGrid posts the summary comment. A session anywhere is
  ended after 30 minutes without activity.
- **Closed sessions reopen when used.** If an ended session gets another
  prompt (a second tab, or a resumed conversation), its run reopens on the
  same ticket.
- **Runs that never closed are retried.** An ended session whose run did not
  close is retried each time a session starts, for up to a week.

## Changed

- **Upload problems are visible.** Uploads run in the background with no
  output. Their last problem is now kept in
  `~/.rustgrid/trace/<session-id>.error` until an upload succeeds, and
  `rustgrid-agent trace status` shows it.

## Compatibility

Works with the same RustGrid as v1.6.3. Session state written by v1.6.3 is
read as is.
