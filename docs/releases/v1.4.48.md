# rustgrid-agent v1.4.48

This patch release enforces the selected mutation fallback policy in the next
provider request so a forced file replacement cannot retry a rejected patch.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Fixed

- Restrict persisted mutation-repair provider requests to the tools permitted
  by their active fallback policy.
- Expose and force only `replace_file` when replacement is selected, preventing
  the provider from invoking `apply_patch` again.
- Preserve the existing normal mutation tool set when no fallback is active and
  after the bounded fallback attempt completes.

## Compatibility and deployment order

Fallback selection, mutation failure identity, repair budgets, validation,
planning, publication, terminal handling, and graph architecture are unchanged.

Artifact publication does not update the production RustGrid backend's agent
download URL and checksum automatically. After the protected release completes,
pin the exact v1.4.48 Linux archive URL and SHA-256 published by the workflow.

## Verification

The release candidate passes formatting, strict Clippy, the full test suite,
package verification, and packaged-source compilation using the pinned Rust
1.94 toolchain. The focused regression verifies that a persisted replacement
fallback exposes and forces `replace_file` without exposing `apply_patch`, while
the initial mutation retains its normal tool set.

## Rollback

Stop new hosted dispatches before restoring the backend worker download URL,
checksum, container deployment, and Homebrew installations to v1.4.47. Do not
replace or mutate the v1.4.48 tag or release assets.
