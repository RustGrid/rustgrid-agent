# rustgrid-agent v1.4.5

This release lets hosted executions gather enough repository context to
complete their implementation impact map instead of stopping at the former
five-call discovery allocation.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Changed

- The 25 percent discovery allocation is now an advisory telemetry target.
  Discovery can continue until the required implementation impact map is
  complete.
- With the default 20-call mission budget, hosted discovery and implementation
  can use up to 17 calls while preserving three calls for independent
  completion review.
- Hosted execution retains the full model turn history until the signed input
  ceiling requires trimming the oldest turns; it no longer discards history
  after eight turns.
- Phase telemetry reports discovery and planning targets and how many calls
  were consumed beyond those targets.

## Fixed

- Prevent broad tasks from becoming incomplete merely because repository
  discovery needed more than five model calls.
- Preserve context gathered across longer discovery sessions so later calls can
  use earlier repository evidence when building the impact map and
  implementation.

## Compatibility and deployment

No control-plane schema, workflow input, or secret change is required. The
signed overall model-call, cost, token, input, and duration limits remain
authoritative, and the worker continues to reserve capacity for independent
completion evaluation.

Canonical workflows must update their pinned agent download URL and SHA-256 to
the v1.4.5 Linux archive before new executions receive this behavior.

This release retains the completion-aware `partial_result` contract introduced
in v1.4.3. Deploy control-plane support for that result before deploying this
worker version.

Artifact publication does not update canonical workflow references or deploy
workers. Regenerate affected workflows and complete staging certification
against the exact published image digest before production promotion.

## Rollback

If rollback is required, stop hosted dispatches and return canonical workflows
to `v1.4.4`. Version 1.4.4 restores the five-call default discovery cutoff and
eight-turn context cap. Do not replace or mutate existing tags or release
assets.
