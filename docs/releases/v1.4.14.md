# rustgrid-agent v1.4.14

This patch release makes hosted write recovery deterministic and prevents
intermediate edit-tool failures from overriding the final repository, diff,
and validation result.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Changed

- Give each planned source change a stable change ID and record ordered tool
  attempts separately from the intended change.
- Reconcile failed attempts with later writes to the same target, final changed
  paths, implementation declarations, tests, and builds before completion
  evaluation.
- Classify attempt history as recovered, superseded, still unresolved, or
  unrelated instead of treating every failed tool call as unfinished work.
- Add `replace_range`, `insert_after_symbol`, `insert_before_symbol`,
  `apply_unified_diff`, and `rewrite_small_file` hosted editing tools.
- Return before and after hashes, changed ranges, and concise diff summaries
  from source-changing tools.
- Preserve passed test and build evidence when the independent completion
  evaluator contributes criterion classifications.

## Fixed

- Recover an ambiguous or absent replacement when the same planned change is
  subsequently applied and verified, even when the textual attempt hashes
  differ.
- Allow a later whole-file rewrite to supersede multiple earlier failures on
  the same target.
- Require an actual later mutation: an earlier success or successful no-op
  cannot recover a later failed edit.
- Bound ambiguous replacement retries and force a range, symbol, unified-diff,
  or small-file rewrite strategy rather than consuming the remaining model
  budget on the same pattern.
- Send only genuinely unresolved intended changes to completion evaluation.
- Keep external review separate from implementation completeness and leave
  review-pending pull requests normally titled.
- Treat persisted and published `complete`,
  `complete_pending_external_review`, `partial`, and `blocked` outcomes as
  healthy worker-process conclusions. Invalid terminal results,
  authentication failures, lost changes, infrastructure failures, and
  publication failures still exit nonzero.

## Compatibility and known limitations

RustGrid must support structured mission outcomes, process health, completion
evaluation, and terminal worker-result precedence. Later workflow-run and
workflow-job webhooks may update workflow and runner diagnostics but must not
replace an already persisted structured worker result.

The worker still requires concrete diff evidence for every satisfied code
criterion. Passing tests or a build alone cannot recover a planned change that
is absent from the final diff.

Artifact publication updates the rustgrid-agent GitHub release, source package,
native binaries, Homebrew formula, SPDX SBOM, attestations, and container. It
does not deploy RustGrid or AgentOps and does not update the canonical workflow
pin.

## Verification

Regression coverage verifies stable change IDs, ordered attempts, semantic
recovery across different hashes, whole-file supersession, no-op and ordering
safety, final-diff precedence, validation evidence, absent-change handling,
bounded ambiguity repair, deterministic editing tools, review-pending and
partial pull-request presentation, and healthy domain outcomes.

The complete locked Rust test suite, strict Clippy, npm quality gate, release
build, formatting, source packaging, secret scan, and diff checks must pass for
this release candidate.

## Rollback

Stop new hosted dispatches before returning canonical workflows and Homebrew
installations to v1.4.13. Do not replace or mutate the v1.4.14 tag or release
assets. Existing branches, pull requests, structured results, and write-attempt
history remain available for inspection and continuation.
