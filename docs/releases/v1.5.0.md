# rustgrid-agent v1.5.0

This minor release lets RustGrid run a task on a disposable VM it creates and
deletes, runs Claude Code as a coding agent, removes the GitHub Actions
execution provider, and updates dependencies with known vulnerabilities.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Added

- `rustgrid-agent bootstrap` exchanges the one-time token in a RustGrid-hosted
  VM's user-data for that VM's worker credential and writes a single-run
  configuration. `serve --exit-after-run` exits once the assigned run ends.
- The `disposable_vm` executor treats the VM as the isolation boundary and runs
  the coding agent and quality gates as an unprivileged user through sudo. It
  refuses a configuration that `bootstrap` did not write.
- Claude Code runs as the coding agent when RustGrid signs a version 2
  execution policy with `agent.provider: "claude"`, reaching Anthropic through
  RustGrid's model gateway with a run-scoped token.
- Optional architecture boundaries from the run manifest are checked after every
  Codex session and escalated instead of crossed.

## Fixed

- A worker keeps taking runs after an attempt fails.
- Required workflows that never appear on the pushed commit are skipped after a
  five-minute discovery window.
- Root-level JavaScript quality gates are skipped in repositories without a
  `package.json`.
- An execution-protocol event built from an older state is reported as a
  revision conflict.

## Security

- rustls and other locked dependencies are updated, clearing RUSTSEC-2026-0285,
  -0346, -0348, -0349, -0381 and -0382. The yanked `async-executor` is replaced.
- The container image moves to Node 24.22.1 with patched `brace-expansion` and
  `undici`.
- `zvariant`, `zbus_names` and `zvariant_derive` are reported unmaintained
  because they merged into zbus 6. They reach the worker only through
  `keyring`'s Linux Secret Service store and are ignored until `keyring` moves.

## Compatibility

- **Removed:** the GitHub Actions execution provider, including the `execute`
  and `report-emergency-failure` commands and the canonical workflow. Use the
  persistent `serve` worker or RustGrid-hosted VMs.
- Version 1 Codex execution policies are read exactly as before.

## Verification

The release candidate must pass formatting, strict Clippy, the full unit and
integration test suite, npm build, package verification, packaged-source
compilation, Homebrew formula syntax validation, and the version smoke test.

## Rollback

Stop new hosted dispatches before restoring the backend worker download URL,
checksum, container deployment, and Homebrew installations to v1.4.55. Do not
replace or mutate the v1.5.0 tag or release assets.
