# rustgrid-agent v1.4.23

This patch release fixes fresh execution-graph initialization and finalizes
mission complexity only after discovery and planning reveal the implementation
scope.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Changed

- Derive separate typed collections for remaining graph nodes, remaining and
  applied mutation targets, and completed validation nodes.
- Give the bootstrap graph only bounded discovery and planning budgets.
- Reclassify complexity after plan acceptance using target and new-file counts,
  test surface, dependency and schema changes, cross-module impact, external
  integrations, and expected validation duration.
- Rebuild mutation, validation, review, completion, and publication budgets
  from the accepted plan while retaining discovery and planning usage.

## Fixed

- Do not evaluate discovery, planning, validation, review, completion, or
  publication nodes as applied repository targets.
- Remove compatibility notebook `remaining_work` from mutation invariant
  evaluation while retaining it as an orchestration display projection.
- Do not interpret `GraphCreated` or `last_successful_action` as repository
  mutation evidence.
- Report applied-target invariant failures with the invariant name, offending
  node IDs, kinds and statuses, and both remaining and applied mutation IDs.
- Restore old discovery/planning-only checkpoints as provisional when their
  serialized classification-stage field is absent.
- Persist a valid fresh graph before dispatching the first discovery request.

## Compatibility, security, and known limitations

Persisted checkpoints remain backward compatible. Pre-plan checkpoints that
predate the explicit classification stage are normalized from their bootstrap
topology; accepted-plan graphs remain authoritative. Existing hosted API,
manifest, credential, and repository-permission contracts are unchanged. This
release adds no credential scope, repository permission, or network access.

Artifact publication updates the GitHub release, native binaries, Homebrew
formula, SBOM, attestations, and container. It does not deploy a production
worker. Production must be updated separately to the exact v1.4.23 Linux
archive URL and SHA-256 after the protected release workflow completes.

## Verification

The complete locked suite passes 425 unit tests, 14 API-contract tests, 10 CLI
tests, and 8 hosted-orchestrator replay tests. Formatting and strict Clippy pass
with warnings denied. Regression coverage includes a fresh discovery/planning
graph, typed mutation and validation projections, graph-created and legacy
action isolation, provisional-to-authoritative reclassification with retained
usage, legacy checkpoint normalization, and an observed discovery HTTP request
after graph persistence.

## Rollback

Stop new hosted dispatches before restoring the RustGrid worker download URL
and SHA, canonical workflows, and Homebrew installations to v1.4.22. Do not
replace or mutate the v1.4.23 tag or release assets. Persisted graph checkpoints
and notebooks remain compatible with v1.4.22.
