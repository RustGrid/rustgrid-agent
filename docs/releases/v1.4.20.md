# rustgrid-agent v1.4.20

This patch release repairs hosted lifecycle recovery after superseded or
duplicate mutations and guarantees that remaining planned targets are not
skipped before validation.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Changed

- Reconcile lifecycle advancement from authoritative per-target state,
  unresolved failures, repository changes, and required validation gates.
- Select the next active target deterministically from derived remaining work
  after every successful mutation.
- Keep implementation running while required targets remain and model-call
  budget is available.

## Fixed

- Mark failed mutations `superseded` when the same target is already applied,
  a later successful mutation satisfies it, or the final diff contains the
  intended target change.
- Classify duplicate writes to applied targets as `target_already_applied`,
  instruct the model to continue with the next target, and avoid repair state
  or unresolved-failure records.
- Permit `repair -> implementation` and `repair -> validation` recovery while
  prohibiting `repair -> completion_evaluation` and
  `validation -> completion_evaluation` shortcuts.
- Require the complete route `validation -> diff_review ->
  completion_evaluation -> publication`.
- Publish a validated useful partial result as a draft pull request when the
  implementation budget expires with explicit remaining targets.

## Compatibility, security, and known limitations

The notebook and hosted API wire formats remain backward compatible. This
release adds no credential scope, repository permission, or network access.
Partial publication requires non-empty changed paths, passing worker-owned
validation, and explicit remaining targets.

Artifact publication updates the GitHub release, native binaries, Homebrew
formula, SBOM, attestations, and container. It does not deploy a production
worker. Production must be updated separately to the exact v1.4.20 Linux
archive URL and SHA-256 after the protected release workflow completes.

## Verification

The complete locked worker suite passes 318 unit tests, 14 API-contract tests,
and 10 CLI tests. Formatting and strict Clippy pass with warnings denied. The
AOPS-226 regression applies all five targets in order, treats a duplicate first
target as already applied, passes validation, reviews the diff, evaluates
completion, commits, pushes, and creates the pull request. Additional tests
cover repair recovery from a superseded failure, illegal transition rejection,
and draft publication of validated useful partial work.

## Rollback

Stop new hosted dispatches before restoring the RustGrid worker download URL
and SHA, canonical workflows, and Homebrew installations to v1.4.19. Do not
replace or mutate the v1.4.20 tag or release assets. Persisted notebooks remain
available for a later continuation attempt.
