# rustgrid-agent v1.6.2

This patch release makes IDE session tracing a one-command setup. It replaces
v1.6.1, which was never released because its container image did not build.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

Then turn on tracing:

```sh
rustgrid-agent trace install
```

## Added

- **`rustgrid-agent trace install`** sets up IDE session tracing. It:
  - writes the Claude Code hooks for the binary's real location into managed
    settings, asking `sudo` for that step (Homebrew installs use the stable
    `bin` link, so upgrades keep working);
  - merges with any settings already there;
  - installs the `/rustgrid-link` command;
  - signs the computer in if needed, then checks that everything works.

  `--user` writes your own settings instead. Device management can run it as
  root with `--no-login`.
- **`rustgrid-agent trace status`** shows whether sessions are traced, where
  the hooks are, whether RustGrid answers, which ticket the current branch links
  to, and the last traced session.
- **`rustgrid-agent trace uninstall`** removes exactly what `install` added.
- **The `/rustgrid-link` command** is added for each person at the start of
  their next Claude Code session if it is missing.
- **The Homebrew formula** tells you how to turn tracing on.

## Fixed

- The container image includes the Claude Code templates `trace install`
  embeds, so it builds again.

## Compatibility

There are no changes to tracing itself, or to `run`, `watch`, `serve` and
`bootstrap`. Hooks installed by hand for v1.6.0 are replaced in place by
`trace install`.

## Verification

The release candidate must pass formatting, strict Clippy, the full unit and
integration test suite, npm build, package verification, packaged-source
compilation, Homebrew formula syntax validation, and the version smoke test.

## Rollback

Run `rustgrid-agent trace uninstall` and reinstall v1.6.0. Do not replace or
mutate the v1.6.2 tag or release assets.
