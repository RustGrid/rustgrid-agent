# rustgrid-agent v1.4.51

This patch release fixes generic validation-repair target selection when a
failed assertion implicates several planned repository targets.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Fixed

- Carry complete planned mutation targets into validation-repair diagnosis so
  target roles and intents remain available to the existing ranking logic.
- Combine exact assertion file and line evidence, import relationships,
  repository contents, and planned target semantics when selecting a repair
  target.
- Prefer updating an exact stale test expectation when the implemented behavior
  already matches the observed value instead of selecting an unrelated source
  file that happens to contain the same values.

## Regression coverage

- Prove exact stale test locations outrank unrelated files containing matching
  assertion values.
- Prove planned implementation intent can select the responsible source target
  when product behavior is incorrect.
- Preserve the existing generic validation-repair ranking coverage without
  encoding ticket-specific behavior.

## Compatibility

No graph architecture, validation command, mutation lifecycle, publication,
budget, terminal handling, or provider-tool routing contract changes in this
release.

The release candidate must pass formatting, strict Clippy, the full unit and
