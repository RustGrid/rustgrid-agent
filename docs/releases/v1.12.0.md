# rustgrid-agent v1.12.0

In this release every new Claude Code conversation starts unlinked from
RustGrid, so a session is traced only on the ticket you choose for it. Each
repository can also choose the prefix of the branches rustgrid-agent creates
for tickets, and ticket titles are no longer cut mid-word in branch names.
Docker Sandboxes can now install Playwright and its browsers.

## Install or upgrade

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

Workers pick up the new version when they restart. There is no need to run
`rustgrid-agent trace install` again.

## Added

- **Configurable branch prefix.** The Git config key `rustgrid.branchPrefix`
  sets the prefix of ticket branches. Set it in one repository:

  ```sh
  git config rustgrid.branchPrefix rustgrid
  ```

  or in every repository with `git config --global`. A repository's own value
  wins over the global one. Both `/rustgrid-link` and cloud runs read it, so
  ADD-437 gets `rustgrid/add-437-<title>`. The value is made ref-safe: each
  `/`-separated part is lowercased and slugged, and an empty value falls back
  to `agent`.

## Changed

- **New conversations start unlinked.** A new Claude Code chat, or `/clear`,
  has no ticket, even on a branch named after one, and its first prompt asks
  for `/rustgrid-link ADD-123`. A branch name no longer links a session by
  itself. `/clear` in a linked session ends that ticket's run at the clear,
  with its summary comment, and anything after the clear waits for the next
  link. Resumed (`--resume`, `--continue`) and compacted conversations keep
  their link.
- **Whole words in branch names.** Ticket titles are still limited to 48
  characters, but they are now cut at the last whole word. For example, a title
  that used to give `…-sign-in-and-registration-d` now gives
  `…-sign-in-and-registration`.

## Fixed

- A trace flush running while a session was relinked could drop the earlier
  ticket's run before ending it, leaving that run open. The run is now kept
  until it is ended.
- New and recovered Docker Sandboxes allow Playwright's browser download CDNs
  and redirect targets, npm, and Ubuntu/Debian system package repositories.
  Codex and Claude Code can install Playwright and matching browsers inside
  their sandbox without changing the host's global network policy.

## Compatibility

- Works with the same RustGrid as v1.11.0. Session state and installed hooks
  are unchanged.
- **Behaviour change:** people who relied on a branch name to link their
  sessions now run `/rustgrid-link` at the start of each conversation.
  Sessions an older version already linked from the branch keep working.
- Without `rustgrid.branchPrefix`, branches start with `agent/` as before.
- Only branches created from now on are named by the new rules. Existing
  branches are not renamed. A run that recorded a branch keeps it. The
  "branch already exists" check compares against the new name, so if a ticket
  has a long title and an older run left a branch cut mid-word, a new run may
  create a branch beside it instead of reporting the old one as stale.
- Cloud runs read the setting from the worker's checkout, so a repository-local
  value must be set in that checkout, or set with `--global` for the worker's
  user.

## Known limitations

- The prefix comes from Git config only. RustGrid project settings do not set
  it yet.
- See [known limitations](../known-limitations.md).

## Verification

The release candidate must pass formatting, strict Clippy, the full unit and
integration test suite, npm build, package verification, packaged-source
compilation, Homebrew formula syntax validation, and the version smoke test.

## Rollback

Reinstall v1.11.0. Do not replace or mutate the v1.12.0 tag or release assets.
Branches created with a custom prefix stay valid after a rollback. New branches
go back to `agent/`, and sessions link from the branch name again.
