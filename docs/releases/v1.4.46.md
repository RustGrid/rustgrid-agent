# rustgrid-agent v1.4.46

This patch release preserves the failure-relevant tail of large validation
output so the existing validation-repair parser can diagnose failed test suites.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Fixed

- Keep validation result summaries bounded at 16 KB while retaining both an
  initial excerpt and a larger failure-relevant tail for non-zero exits.
- Preserve late failing-test names, assertion details, and source locations for
  the existing validation failure parser after verbose passing-test output.
- Leave successful validation summaries and the existing command runner and
  parser unchanged.

## Compatibility and deployment order

Discovery, planning, implementation, mutation, validation-repair nodes,
publication, terminal handling, budgets, and cycle detection are unchanged.
The downstream recovery-publication conflict is outside this release.

Artifact publication does not update the production RustGrid backend's agent
download URL and checksum automatically. After the protected release completes,
pin the exact v1.4.46 Linux archive URL and SHA-256 published by the workflow.

## Verification

The release candidate passes formatting, strict Clippy, 612 library tests, 14
API contract tests, 10 CLI tests, 8 hosted-orchestrator replay tests, and
packaged-source compilation using the pinned Rust 1.94 toolchain. The focused
regression verifies that a large passing-test prefix followed by a failure still
produces a parsed failing test, source line, and implicated path within the
bounded summary.

## Rollback

Stop new hosted dispatches before restoring the backend worker download URL,
checksum, container deployment, and Homebrew installations to v1.4.45. Do not
replace or mutate the v1.4.46 tag or release assets.
