# rustgrid-agent v1.4.52

This patch release enforces active repository-mutation fallback policies at the
serialized provider-request boundary.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Fixed

- Preserve the existing mutation-repair decision after a failed mutation turn
  instead of replacing it during the final reconciliation before dispatch.
- When the active fallback permits only `replace_file`, serialize only that
  tool and use the existing explicit named function tool choice.
- Keep normal initial mutation requests unchanged, including their existing
  `apply_patch` and `replace_file` tool surface.

## Regression coverage

- Drive a normal mutation request through an `invalid_patch_target` failure.
- Prove the worker selects `force_replace_file` with
  `permitted_tools = ["replace_file"]`.
- Inspect the immediately following `/ai/responses` payload and prove it
  contains exactly `replace_file`, omits `apply_patch`, and names
  `replace_file` as its tool choice.
- Keep the generic hosted pull-request golden path green.

## Dependencies

- `base64` 0.23.1
- `clap` 4.6.5
- `keyring` 4.1.6
- `actions/attest` 4.2.2, pinned by immutable commit

## Compatibility

No fallback selection, mutation failure classification, attempt accounting,
budgets, graph architecture, validation, publication, or terminal behavior is
changed in this release.

## Verification

The release candidate must pass formatting, strict Clippy, the full unit and
integration test suite, npm build, package verification, packaged-source
compilation, Homebrew formula syntax validation, and the version smoke test.

## Rollback

Stop new hosted dispatches before restoring the backend worker download URL,
checksum, container deployment, and Homebrew installations to v1.4.51. Do not
replace or mutate the v1.4.52 tag or release assets.
