# rustgrid-agent v1.4.2

This hotfix prevents hosted implementation sessions from wasting their model
budget on shell syntax that the direct-process tool does not support, and
preserves valid work when the final model call is consumed.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Added

- Hosted agents now have a bounded `replace_text` tool that replaces one exact,
  unique string in an existing UTF-8 repository file.

## Fixed

- Focused commands reject shell operators, pipelines, redirects, heredocs, and
  chained commands with an explicit diagnostic.
- Non-zero focused-command exits are returned to the model as failures instead
  of false-positive successes.
- If the implementation model exhausts its configured call budget after
  producing a diff, RustGrid continues into its authoritative quality gates and
  can publish the change when those gates pass.
- Empty implementations and repair sessions that cannot fix failing gates
  continue to fail closed.
