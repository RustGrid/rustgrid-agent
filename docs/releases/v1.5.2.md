# rustgrid-agent v1.5.2

This patch release fixes RustGrid-hosted VM runs, where every npm quality gate
failed because the coding agent inherited the worker's home directory.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Fixed

- The `disposable_vm` executor no longer passes the worker's `HOME`, `USER`,
  `LOGNAME`, `SHELL`, `MAIL`, `TMPDIR` or `XDG_*` variables through `sudo`, so
  `sudo -H` gives the run user its own home. Before, `npm ci` failed with
  `EACCES` on the worker's private `~/.npm`, and every later gate failed with
  it.

## Compatibility

Only the `disposable_vm` executor changes. Local and Docker Sandboxes workers
behave as in v1.5.0. Version 1.5.1 was never released.

## Verification

The release candidate must pass formatting, strict Clippy, the full unit and
integration test suite, npm build, package verification, packaged-source
compilation, Homebrew formula syntax validation, and the version smoke test.

## Rollback

Restore the backend worker download URL and checksum to v1.5.0. Do not replace
or mutate the v1.5.2 tag or release assets.
