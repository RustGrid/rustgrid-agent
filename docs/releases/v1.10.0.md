# rustgrid-agent v1.10.0

This release makes every cloud run start from a fresh branch, so changes left
by an earlier run on the same ticket can no longer mix into a new
implementation.

## Install or upgrade

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

Workers pick up the new version when they restart. There is no need to run
`rustgrid-agent trace install` again.

## Changed

- **Each run starts from a fresh branch.** A run used to work on the ticket's
  branch `agent/<key>-<title>`. If an earlier run had already pushed that
  branch, publication reconciled the new commit onto the old commits and
  reused the old open pull request, so a previous attempt's changes ended up
  in the new one. The worker now checks whether that branch already exists,
  locally or on GitHub. If it does, the run creates
  `agent/<key>-<title>-<run-id>` from the base branch and opens its own pull
  request.
- **The stale branch is reported, not changed.** The existing branch, and any
  pull request on it, is left as it is. The run names it in the
  `branch_create` step (message and a new `stale_branch` field), in a "Stale
  branch" section of the pull request body, and in the run summary.
- **Recovery is unchanged.** A run resuming its own work, from its journal or
  a recovery journal, keeps the branch it recorded. Runs with `fresh_start`
  still use a per-run branch.

## Compatibility

- Works with the same RustGrid as v1.9.1. Session state and installed hooks
  are unchanged.
- The branch check needs the run's GitHub token before the branch is created.
  It uses the token the run already has, with the same permissions.

## Known limitations

- Stale branches and their pull requests are not closed or deleted. Review
  and close them on GitHub when they are no longer needed.
- See [known limitations](../known-limitations.md).

## Verification

The release candidate must pass formatting, strict Clippy, the full unit and
integration test suite, npm build, package verification, packaged-source
compilation, Homebrew formula syntax validation, and the version smoke test.

## Rollback

Reinstall v1.9.1. Do not replace or mutate the v1.10.0 tag or release assets.
