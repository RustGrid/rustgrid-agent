# rustgrid-agent v1.6.0

This minor release traces Claude Code sessions that people run in their IDE
onto the RustGrid ticket they work on, so the ticket shows what Claude Code did
and what it cost.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

Then sign in once with `rustgrid-agent login`.

## Added

- `rustgrid-agent trace hook <event>` runs from Claude Code hooks. Each hook
  records the session under `~/.rustgrid/trace` and returns at once. A detached
  `rustgrid-agent trace flush` uploads what is new in the session transcript to
  the session's interactive run:
  - prompts and Claude's replies;
  - activity steps;
  - commands with their exit code and a short, redacted output excerpt;
  - edited file paths;
  - token usage, which RustGrid prices;
  - pull requests.

  When the session ends, RustGrid posts one summary comment on the ticket.
- A session links to its ticket from the branch name (`agent/add-354-…`,
  `rustgrid/ADD-12`) or with `/rustgrid-link ADD-354`. Prompts are blocked
  until the session is linked and the computer is signed in. RustGrid being
  unreachable never blocks a prompt.
- Secrets are redacted before anything leaves the machine. File contents, full
  command output, thinking and images are never sent.
- `packaging/claude-code/` holds the managed-settings hooks and the
  `/rustgrid-link` command for rolling tracing out so users cannot turn it off.
  See [IDE session tracing](../ide-session-tracing.md).

## Compatibility

Tracing needs a RustGrid control plane with interactive runs
(`POST /api/v1/agent-runs/interactive`). Worker behaviour for `run`, `watch`,
`serve` and `bootstrap` is unchanged from v1.5.2.

## Known limitations

- Only Claude Code sessions are traced.
- Before relying on managed settings to make tracing mandatory, confirm on a
  test machine that a user's own `disableAllHooks` does not disable the managed
  hooks with your Claude Code version.
- The managed-settings template calls `/usr/local/bin/rustgrid-agent`. Homebrew
  on Apple Silicon installs to `/opt/homebrew/bin`, so either symlink the binary
  or edit the hook commands.

Remove the hooks from managed settings and reinstall v1.5.2. Do not replace or
