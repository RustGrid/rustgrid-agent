# rustgrid-agent v1.4.53

This patch release allows failed hosted validation commands to continue through
the existing validation-diagnosis and repair lifecycle.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Fixed

- Persist the validation ledger using the backend's existing bounded execution
  graph checkpoint event contract after a validation process completes.
- Keep a non-zero exit code as failed validation-domain evidence and continue
  into structured assertion parsing, failure revision creation, repair-target
  selection, and the existing validation-repair route.
- Preserve the full captured validation evidence and the unchanged passing-gate
  lifecycle.

## Regression coverage

- Prove a focused validation command can complete with exit code 1, persist its
  checkpoint, parse structured failure evidence, and create a recoverable
  validation failure revision without `execution_event_invalid`.
- Prove exit code 0 continues through the existing passing-validation path.
- Keep the hosted pull-request golden path and serialized `replace_file`-only
  mutation fallback regression green.

## Compatibility

No validation command execution, timeout, output capture, repair selection,
mutation fallback, publication, budget, graph, or terminal behavior changes in
this release.

## Verification

The release candidate must pass formatting, strict Clippy, the full unit and
integration test suite, npm build, package verification, packaged-source
compilation, Homebrew formula syntax validation, and the version smoke test.

## Rollback

Stop new hosted dispatches before restoring the backend worker download URL,
checksum, container deployment, and Homebrew installations to v1.4.52. Do not
replace or mutate the v1.4.53 tag or release assets.
