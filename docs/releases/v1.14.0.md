# rustgrid-agent v1.14.0

In this release Claude Code IDE sessions hear about an architect's decision
while they work, instead of only when the ticket is linked again. IDE
sessions also can no longer edit the architecture contract's protected paths,
and the worker's diff check now enforces those paths for cloud runs too.

## Install or upgrade

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
rustgrid-agent trace install
```

Run `rustgrid-agent trace install` again on each computer that traces IDE
sessions, to add the new `PreToolUse` hook; `trace status` says when it is
missing. Workers pick up the new version when they restart.

## Added

- **Live architect decisions in IDE sessions.** On every prompt, the trace
  hook asks RustGrid what changed on the session's ticket
  (`GET /api/v1/agent-runs/{run_id}/updates`, RustGrid API 2.3.0), waiting at
  most 3 seconds per request.
  - When an escalation on the ticket is approved, rejected or raised, it
    rewrites `architecture.md` and Claude tells you in plain terms, for
    example "Architect approved protected-1,3,4,5,6 for RUSTGRID-33: Add it to
    core."
  - When the ticket's title, status or description changes, it rewrites
    `ticket.md` and gives Claude the new text.
  - A new contract version is announced but not loaded. The session stays on
    the version it was linked under, until a new conversation links again.
  - Each change is told once per session, even when RustGrid sends it again or
    another session in the same checkout saw it first.
  - If RustGrid can't be reached, the session carries on with the copy it
    already has and Claude says so once, not on every prompt.
- **`rustgrid-agent trace check`** runs the same check by hand for the session
  linked in the current folder (or `--session <id>`) and prints what changed.
  Claude hears about it with the next prompt.
- **Protected paths in IDE sessions.** A `PreToolUse` hook blocks Claude's
  file edits (`Edit`, `Write`, `MultiEdit`, `NotebookEdit`) to `read_only`
  paths, and to `ask` paths until an architect approves an escalation for the
  boundary. An approval reaches the hook with the next prompt through the live
  updates, without linking again. The hook reads only local files and lets an
  edit through on any problem.

## Fixed

- **The worker's diff check enforces protected paths.** They used to reach the
  agent only as prompt text. A change to a `read_only` path now fails the run
  as a human-intervention block, even after an approval. A change to an `ask`
  path raises an escalation unless an architect already approved that
  boundary. Both apply when the ticket declares no boundaries.

## Security

- The container image moves to Node 24.22.3, which fixes the High-severity
  Node CVEs the image scan reported in 24.22.1.
- `url` moves to 2.5.9 for RUSTSEC-2026-0592, a stack overflow in
  `Url::origin()` on nested `blob:` URLs. The agent never calls
  `Url::origin()`.

## Compatibility

- Live updates need RustGrid API 2.3.0. Against an older RustGrid, the first
  prompt of a session says once that live updates are not available. The
  session then works as in v1.13.0, with the contract and ticket loaded at
  link time.
- Sessions behind the AgentOps proxy need `/agent-runs/{run_id}/updates` on
  its allowlist. Until then they are told once that the check failed.
- Sessions linked by v1.13.0 keep working. Their first check treats what the
  link wrote as known, and does not repeat it.
- The execution manifest version (`2`) is unchanged. Projects without an
  architecture are unaffected.

## Known limitations

- Live updates cover escalations, the contract version and the ticket's title,
  status and description. New comments and attachments are not reported.
- The `PreToolUse` hook does not see shell commands, so a write through `Bash`
  is not blocked. The runner and review remain the authority.
- See [known limitations](../known-limitations.md).

## Verification

The release candidate must pass formatting, strict Clippy, the full unit and
integration test suite, `cargo-deny`, npm build, package verification,
packaged-source compilation, Homebrew formula syntax validation, and the
version smoke test.

## Rollback

Reinstall v1.13.0. Do not replace or mutate the v1.14.0 tag or release assets.
After a rollback, IDE sessions learn about decisions only when linked again,
`trace check` is gone, and protected paths are no longer blocked in IDE
sessions. Run `rustgrid-agent trace install` with v1.13.0 to remove the
`PreToolUse` hook; if it stays, v1.13.0 lets every edit through.
