# rustgrid-agent v1.4.11

This patch release lets a later hosted GitHub Actions attempt detect and
continue a structured partial implementation without restarting the mission
from repository discovery.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Changed

- Detect a resumable partial run only when a later mission attempt resumes the
  deterministic branch, finds RustGrid's explicitly incomplete draft pull
  request, and confirms preserved changes relative to the signed base SHA.
- Read the pull request's `Remaining work` section and provide it, the pull
  request number, and every preserved changed path to the continuing worker.
- Restore an authoritative worker notebook when available. If notebook
  metadata is missing or stale, reconstruct a planning checkpoint from the
  signed mission, acceptance criteria, pull request, and existing diff.
- Emit `worker.partial_run_detected` telemetry with the actual resume phase and
  continuation evidence.

## Fixed

- Preserve correct prior changes instead of restarting, duplicating, or
  overwriting them on a later GitHub Actions attempt.
- Avoid treating an unrelated draft pull request as a partial RustGrid run.
- Keep clean branches and first attempts on the normal fresh-run path.

## Compatibility and deployment

This release changes the hosted worker only. The canonical workflow must pin
the new v1.4.11 artifact before new hosted attempts use continuation-aware
startup.

RustGrid must accept and preserve the worker's structured partial-result
lifecycle, and AgentOps must expose the continuation action, for the complete
partial-result experience. Artifact publication does not deploy those
downstream services or update canonical workflow pins.

## Verification

Regression tests cover positive partial-run detection, rejection of first
attempts, clean branches, non-resumed branches and non-draft pull requests,
remaining-work parsing, continuation prompt construction, acceptance-criteria
recovery, and planning-phase notebook reconstruction.

The complete Rust test suite, strict Clippy, formatting, npm quality gate, and
release build pass for this release candidate.

## Rollback

Stop new hosted dispatches before returning canonical workflows to v1.4.10.
Do not replace or mutate existing tags or release assets. Draft pull requests
and deterministic branches created by v1.4.11 remain ordinary Git objects and
can be inspected or continued manually after rollback.
