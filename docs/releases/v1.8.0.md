# rustgrid-agent v1.8.0

This minor release loads a ticket's description and attachments into the IDE
session when you link it, and keeps tracing working after the computer signs
in again.

## Install or upgrade

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

Restart Claude Code after upgrading.

## Added

- **`/rustgrid-link` loads the whole ticket.** Claude gets the ticket's
  title, type, status, priority and description, plus the local path of each
  attachment, so the session starts from the full ticket. The ticket is saved
  as `.git/rustgrid-agent/tickets/<KEY>/ticket.md` in the repository, which
  git never commits. Attachments download in the background into the
  `attachments` folder next to it: at most 50 files, 25 MB each and 100 MB in
  total, skipping files flagged by the virus scan, each checked against its
  SHA-256. Loading stays inside the prompt hook's time limit; if it can't
  finish in time, the session is still linked and Claude says so.

## Fixed

- **A reopened run gets a fresh summary.** Each close of a reopened IDE run
  is now a new request, so RustGrid writes a summary for the latest prompt
  instead of replaying the first one.
- **Signing in again no longer stalls a session's uploads.** RustGrid
  refuses writes to runs an earlier sign-in started. The refused upload used
  to be retried on every hook, blocking the session's later replies and its
  run's close. Refused telemetry is now skipped and the rest still uploads. If
  RustGrid refuses the run's prompts and replies too, the session stops
  uploading to that run and `rustgrid-agent trace status` explains why.

## Compatibility

- Works with the same RustGrid as v1.7.0. Session state written by v1.7.0 is
  read as is.
- Loading a ticket's content needs RustGrid to let the worker credential read
  the ticket, its attachment list and attachment downloads for an IDE
  session's ticket. Where it doesn't, linking works as before and Claude
  reports the content as unavailable.
- Runs started before the computer signed in again stay refused until
  RustGrid lets a new worker on the same account write to them.

## Known limitations

- A ticket linked from the branch name is traced without its content; run
  `/rustgrid-link` to load it.
- See [known limitations](../known-limitations.md).
