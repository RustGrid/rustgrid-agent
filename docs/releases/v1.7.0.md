# rustgrid-agent v1.7.0

This minor release lets Codex run on the tenant's OpenAI API key through the
RustGrid model gateway, the way Claude Code runs on the Anthropic key, and
closes a traced IDE session's run as soon as it opens a pull request.

## Install or upgrade

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

Restart Claude Code after upgrading.

## Added

- **Codex through the model gateway.** When RustGrid signs a version 2 policy
  with `agent.provider: "codex"`, the worker requests a run-scoped gateway
  token for each session and points Codex at
  `<API URL>/agent-gateway/openai/v1` with a worker-owned model provider. The
  tenant's OpenAI key stays in RustGrid, and the worker needs no Codex login,
  so RustGrid-hosted runs can use any Codex model RustGrid serves through the
  API key. Version 1 policies keep using the worker's own Codex login,
  unchanged. A gateway Codex policy may not set a model provider, profile,
  local provider, or base URL. See
  [the worker run contract](../worker-api-contract.md#agent-providers-and-policy-versions).

## Changed

- **A pull request closes the IDE session's run.** When the turn that opened a
  pull request finishes, its run closes: the ticket shows the agent report and
  the summary comment, with the pull request attached. Another prompt reopens
  the run, which closes again only when it opens another pull request.

## Compatibility

- Works with the same RustGrid as v1.6.4. Session state written by v1.6.4 is
  read as is.
- Gateway Codex runs need RustGrid to serve `/agent-gateway/openai`, issue
  gateway tokens for version 2 Codex policies, and hold the tenant's OpenAI
  connection. Until it does, RustGrid keeps signing version 1 Codex policies
  and nothing changes.
- Workers before v1.7.0 accept a version 2 Codex policy but run it on their own
  Codex login. Upgrade every worker in a tenant before RustGrid signs version 2
  Codex policies.

## Verification

The release candidate must pass formatting, strict Clippy, the full unit and
integration test suite, npm build, package verification, packaged-source
compilation, Homebrew formula syntax validation, and the version smoke test.

## Rollback

Reinstall v1.6.4. Do not replace or mutate the v1.7.0 tag or release assets.
Roll back workers only after RustGrid stops signing version 2 Codex policies.
