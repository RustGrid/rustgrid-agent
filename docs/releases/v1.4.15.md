# rustgrid-agent v1.4.15

This patch release makes hosted impact-map handling deterministic, versioned,
and recoverable across the worker, RustGrid API, and AgentOps event viewer.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Changed

- Define `rustgrid.impact_map.v2` as a canonical JSON Schema and generate the
  worker Rust types, TypeScript projection, server validator, and drift hashes
  from that source.
- Normalize semantically sufficient legacy impact maps without spending an
  artifact-repair call, and reject unknown fields or dangling evidence IDs with
  precise JSON paths.
- Preserve inspected files, repository searches, criterion IDs, and evidence
  references in the hosted notebook so continuation does not repeat discovery.
- Emit structured impact-map attempt, fallback, repair, accounting, process
  health, and mission-outcome facts for RustGrid and AgentOps.
- Show readable impact-map validation, deterministic fallback, and resumable
  repair summaries in the AgentOps hosted event trail.

## Fixed

- Continue directly to planning when discovery is sufficient and a deterministic
  fallback satisfies the versioned impact-map contract.
- Keep structurally invalid model output distinct from missing or semantically
  partial output, and reserve compact repair only for the invalid layer.
- Prevent malformed impact-map artifacts from reaching persistence by enforcing
  the schema version, schema hash, evidence vocabulary, and required fields at
  the RustGrid event-ingestion boundary.
- Make generated contract drift fail in CI instead of allowing hand-edited Rust,
  TypeScript, schema, or server-validator copies to diverge.

## Compatibility and known limitations

RustGrid must be deployed with the matching `rustgrid.impact_map.v2` ingestion
validator before workers begin emitting the new contract. AgentOps should be
deployed with the matching generated TypeScript projection to render the new
event facts.

Artifact publication updates the rustgrid-agent GitHub release, source package,
native binaries, Homebrew formula, SPDX SBOM, attestations, and container. The
RustGrid worker download URL and SHA remain protected deployment configuration
and must be updated separately after release assets are published.

## Verification

Regression coverage exercises canonical and legacy normalization, unknown-field
and evidence-reference rejection, deterministic fallback, notebook evidence,
precise JSON paths, compact repair, continuation, accounting, process health,
and cross-repository contract drift. The complete locked Rust suite, strict
Clippy, formatting, RustGrid contract tests, AgentOps test suite, and production
build pass for this release candidate.

## Rollback

Stop new hosted dispatches before returning the RustGrid worker download URL and
SHA, canonical workflows, and Homebrew installations to v1.4.14. Do not replace
or mutate the v1.4.15 tag or release assets. Existing notebooks and events retain
their explicit schema version and hash for audit and continuation.
