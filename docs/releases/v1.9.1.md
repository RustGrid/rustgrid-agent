# rustgrid-agent v1.9.1

This patch release stops agent runs from being blocked by a required GitHub
workflow that was skipped rather than run.

## Install or upgrade

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

Workers pick up the new version when they restart. There is no need to run
`rustgrid-agent trace install` again.

## Fixed

- **A skipped required workflow no longer blocks the run.** A repository can
  run CI only on a schedule, on manual dispatch, or when a pull request has a
  label such as `run-ci`. On an unlabeled agent pull request GitHub still
  creates the CI run, but every job is skipped and the run concludes as
  `skipped`. The worker counted any non-success conclusion as a failure, and
  because a skipped run cannot be repaired, the run ended as a permanent
  external failure. A required workflow or check that completes as `skipped`
  or `neutral` now counts as not run: it is accepted as soon as it completes,
  and the `required_workflows` step reports it as skipped by its trigger
  conditions, with the names in a new `not_run` field.
- **Failure diagnostics leave out skipped jobs.** When a required workflow
  does fail, the worker no longer requests logs for its skipped jobs, which
  GitHub answers with 404 `BlobNotFound`, and no longer lists skipped steps as
  failed steps.

## Compatibility

- Works with the same RustGrid as v1.9.0. Session state and installed hooks
  are unchanged.
- Success, failure, cancelled, timed-out and unrecognised conclusions behave
  as before.

## Known limitations

- If the label that enables CI is added after the skipped run completes, the
  worker has already moved on. The labeled run still gates the pull request on
  GitHub.
- See [known limitations](../known-limitations.md).

## Verification

The release candidate must pass formatting, strict Clippy, the full unit and
integration test suite, npm build, package verification, packaged-source
compilation, Homebrew formula syntax validation, and the version smoke test.

## Rollback

Reinstall v1.9.0. Do not replace or mutate the v1.9.1 tag or release assets.
