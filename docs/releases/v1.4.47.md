# rustgrid-agent v1.4.47

This patch release allows separate mutation attempts against the same repository
target to persist distinct failure records.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Fixed

- Include the existing structured mutation-fallback attempt ordinal in mutation
  failure IDs.
- Allow a later failed mutation attempt against the same node, target,
  repository fingerprint, and diagnostic to be recorded independently.
- Keep duplicate-ID rejection unchanged for conflicting or repeated failure
  identities, and preserve deterministic event-stream replay.

## Compatibility and deployment order

Mutation fallback behavior, tool routing, validation, repair-node architecture,
planning, publication, budgets, cycle detection, and terminal handling are
unchanged.

Artifact publication does not update the production RustGrid backend's agent
download URL and checksum automatically. After the protected release completes,
pin the exact v1.4.47 Linux archive URL and SHA-256 published by the workflow.

## Verification

The release candidate passes formatting, strict Clippy, 613 library tests, 14
API contract tests, 10 CLI tests, 8 hosted-orchestrator replay tests, and
packaged-source compilation using the pinned Rust 1.94 toolchain. The focused
regression records two failures for distinct attempts against one target and
replays the exact event stream to the same materialized failure state.

## Rollback

Stop new hosted dispatches before restoring the backend worker download URL,
checksum, container deployment, and Homebrew installations to v1.4.46. Do not
replace or mutate the v1.4.47 tag or release assets.
