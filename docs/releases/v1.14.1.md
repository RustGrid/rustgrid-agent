# rustgrid-agent v1.14.1

This patch fixes two bugs in the live architect decisions that v1.14.0 added to
Claude Code IDE sessions: old decisions announced again after an upgrade, and
decisions listed out of order in `architecture.md`.

## Install or upgrade

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

No need to run `rustgrid-agent trace install` again; the hooks are unchanged.
Workers pick up the new version when they restart.

## Fixed

- **Old decisions are no longer announced again after an upgrade.** A session
  linked under v1.13.0 or earlier, on a ticket with 20 or more decided
  escalations, was told about decisions older than its link on its first
  check, as if they were new. v1.13.0 saved decisions without their times, so
  the session had no cutoff. The cutoff now comes from RustGrid's times for
  the decisions the link had.
- **Architect decisions stay newest first in `architecture.md`.** Decisions
  saved by v1.13.0 had no time and were ranked as the newest, so later
  decisions listed below them. They now take the time RustGrid sends on the
  session's first check. Decision times are compared as times rather than as
  text, so time zone offsets and fractions of a second order correctly.

## Compatibility

- No change to RustGrid API requirements (live updates still need API 2.3.0),
  the execution manifest version (`2`), or the hooks.
- Session state gains one optional field, `decided_before_pending`. v1.14.0
  ignores it, so rolling back is safe.

## Known limitations

- A decision saved without a time that RustGrid never sends again stays at the
  top of the list. RustGrid resends every decision on a session's first check,
  so this is not expected in practice.
- See [known limitations](../known-limitations.md) and the
  [v1.14.0 notes](v1.14.0.md).

## Verification

The release candidate must pass formatting, strict Clippy, the full unit and
integration test suite, `cargo-deny`, npm build, package verification,
packaged-source compilation, Homebrew formula syntax validation, and the
version smoke test.

## Rollback

Reinstall v1.14.0. Do not replace or mutate the v1.14.1 tag or release assets.
After a rollback, the two bugs above return; nothing else changes.
