# rustgrid-agent v1.4.42

This patch release publishes the phase-scoped lifecycle and typed evidence
architecture prepared in v1.4.41, with compatibility for the release pipeline's
pinned Rust 1.94 strict Clippy gate.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Changed

- Separate repository-operation verification, implementation-barrier proof,
  validation-gate results, diff review, completion evaluation, and publication
  evidence into explicit proof classes.
- Scope invariant evaluation to lifecycle phases where its evidence can
  legally exist and validate evidence-producer ordering at startup.
- Resolve implementation, validation, terminal phase, and resumability state
  deterministically from the persisted execution graph.
- Emit structured invariant, barrier, future-evidence suppression, and
  next-implementation-node telemetry.

## Fixed

- Do not require automated validation after an individual repository operation
  while other required implementation targets remain unresolved.
- Continue multi-target, fallback, and already-applied execution without
  replaying completed work or prematurely entering validation.
- Bind validation to the current full-repository fingerprint, stale it after a
  later repair, and require it only for downstream lifecycle decisions.
- Preserve exact invariant category, code, phase, and resumability across
  runtime failures, canonical results, execution projections, and callbacks.
- Use a Rust 1.94-compatible minimal boolean predicate for legacy
  already-applied implementation satisfaction.

## Compatibility and deployment order

The CLI commands, signed manifest, hosted HTTP endpoints, reducer ordering,
repair-budget isolation, callback outbox, and terminal authority remain
unchanged. New evidence variants and resumability metadata are additive, while
legacy completed and already-applied checkpoints retain replay compatibility.

Artifact publication does not update the production RustGrid backend's agent
download URL and checksum automatically. After the protected release completes,
pin the exact v1.4.42 Linux archive URL and SHA-256 published by the workflow.

## Verification

The release candidate passes formatting and strict Clippy using the pinned Rust
1.94 toolchain, 600 library tests, 14 API contract tests, 10 CLI tests, 8 hosted
orchestrator replay tests, the repository build, formula syntax, and compilation
from the packaged source archive.

## Rollback

Stop new hosted dispatches before restoring the backend worker download URL,
checksum, container deployment, and Homebrew installations to v1.4.40. Do not
replace or mutate the v1.4.42 tag or release assets. Additive checkpoint,
evidence, telemetry, and terminal fields may remain stored during rollback.
