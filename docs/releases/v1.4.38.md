# rustgrid-agent v1.4.38

This patch release makes validation repair bounded, replay-safe, and fully
observable while preserving canonical domain outcomes when lifecycle
persistence is degraded.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Changed

- Derive validation-repair budgets from structured failure assertions,
  implicated targets, required-gate criticality, target size, and remaining
  signed mission capacity.
- Persist bounded repair calls, repository writes, context rebuilds,
  reallocations, and attempt identities for deterministic recovery.
- Emit repair telemetry bound to the session, graph revision, repository
  fingerprint, target, assertion set, validation rerun, and local and mission
  budget state.
- Preserve typed phase-persistence degradation in the worker notebook and
  canonical terminal telemetry.

## Fixed

- Prevent repair capacity from exceeding target, call, cost, write, context,
  or mission limits during retries and reallocations.
- Keep cancellation and lease loss distinct from generic failures and keep
  late phase-persistence errors out of initialization-failure taxonomy.
- Preserve healthy complete and partial-reviewable outcomes when phase
  persistence is degraded, while exposing degraded process health and a stable
  machine error code.
- Bind every repair attempt to its exact semantic model call and record
  admission rejection without fabricating a provider attempt.
- Validate versioned phase-transition payloads at both boundaries and require
  `review_incomplete_diff` for repair-to-incomplete-review transitions.

## Compatibility and deployment order

The backend phase-transition validator must be deployed from RustGrid commit
`80875fca035a2dfaefc258307e8b956681c47b39` before hosted workers are pinned to
v1.4.38. The agent continues to accept the existing signed manifest and
terminal callback contracts; new persistence-degradation fields are additive.

Artifact publication does not update the production RustGrid backend's agent
download URL and checksum automatically. After the protected release completes,
pin the exact v1.4.38 Linux archive URL and SHA-256 published by the workflow.

## Verification

The final agent source passes formatting, strict Clippy, 583 library tests, 14
API contract tests, 10 CLI tests, 8 hosted replay tests, and offline packaged
source compilation. The coordinated backend transition contract passes its
focused test, strict Clippy, formatting, and diff checks.

Regression coverage includes bounded repair reallocation and attempt history,
repository-write and context-rebuild exhaustion, semantic model-call identity,
validation-rerun telemetry, late persistence taxonomy, canonical degraded
terminal outcomes, and backend rejection of invalid phase transitions.

## Rollback

Stop new hosted dispatches before restoring the backend worker download URL,
checksum, container deployment, and Homebrew installations to v1.4.37. Do not
replace or mutate the v1.4.38 tag or release assets. The backend validation is
forward-compatible and may remain deployed during an agent rollback.
