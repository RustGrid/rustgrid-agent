# rustgrid-agent v1.4.25

This patch release directs localized discovery into a compact impact-map
finalization call, admits that call against its actual bounded cost profile,
and preserves collected evidence with a deterministic fallback when necessary.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Changed

- Select explicit `InspectRepository`, `FinalizeImpactMap`, and
  `RepairImpactMap` actions from persisted repository evidence and artifact
  state.
- Restrict inspection to repository-reading tools with a 4,096-token output
  cap; restrict finalization and repair to forced `record_impact_map` calls with
  a 2,048-token cap and low reasoning effort.
- Estimate model-call admission from the exact serialized action request and
  report the full projected cost inequality in admission telemetry.
- Validate that node cost budgets can reasonably fund their configured call
  allowances before graph execution.

## Fixed

- Admit compact third discovery calls that fit the remaining node cost budget
  instead of pricing them with the generic maximum-output profile.
- Construct a conservative, normally validated fallback impact map from only
  persisted inspected paths, repository evidence, related tests, ticket
  criteria, searches, and architecture findings when model finalization cannot
  fit.
- Classify localized-discovery policy guidance as `ActionRedirected`, exclude
  it from terminal failed-tool operations, and move directly to impact-map
  finalization.
- Apply an orchestration decision only once for a graph revision, node attempt,
  and action kind.

## Compatibility, security, and known limitations

Persisted notebooks accept the new decision-idempotency checkpoint through a
defaulted optional field. Existing graph, evidence, and budget checkpoints
remain readable. No credential scope, repository permission, or provider
network access is added.

The coordinated RustGrid backend terminal-outcome precedence fix is merged.
Its production deployment remains a separate operational boundary from this
agent release.

Artifact publication updates the GitHub release, native binaries, Homebrew
formula, SBOM, attestations, and container. It does not update the production
worker artifact pin automatically. Production must use the exact v1.4.25 Linux
archive URL and SHA-256 published by the completed protected workflow.

## Verification

The complete suite passes 439 unit tests, 14 API-contract tests, 10 CLI tests,
and 8 hosted-orchestrator replay tests. Formatting and strict Clippy pass.
Focused coverage proves the two-stage localized-discovery transition,
finalization-only tool envelope, compact third-call admission, complete cost
diagnostics, conservative Attempt 25 fallback paths, planning readiness, and
decision idempotency. The coordinated backend `blocked_no_diff` precedence
regression also passes.

## Rollback

Stop new hosted dispatches before restoring the RustGrid worker download URL
and SHA, canonical workflows, and Homebrew installations to v1.4.24. Do not
replace or mutate the v1.4.25 tag or release assets. Existing execution
checkpoints remain backward readable.
