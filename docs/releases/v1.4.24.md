# rustgrid-agent v1.4.24

This patch release admits the first discovery model call correctly, makes
model-call reservations atomic, and preserves authoritative structured worker
outcomes when later GitHub workflow observations arrive.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Changed

- Track reserved and consumed model calls separately and expose the remaining
  call allowance without double-counting active reservations.
- Give discovery up to three provisional model calls and planning up to two,
  with bounded cost and duration limits before authoritative classification.
- Keep discovery running until an impact map, deterministic fallback, concrete
  repository blocker, or actual exhausted budget provides a terminal reason.
- Emit `worker.model_call_admission_evaluated` with node and mission call and
  cost accounting for every preflight decision.
- Return process exit code zero for structured healthy `blocked_no_diff`
  outcomes while retaining the blocked execution-domain result.

## Fixed

- Admit a request when `used_calls + calls_to_reserve` exactly equals the node
  maximum; reject only requests that would exceed it.
- Reserve capacity before provider contact and reconcile it after success,
  provider failure, or a pre-contact failure.
- Prevent an active reservation from admitting a duplicate concurrent call.
- Preserve `mission_outcome`, `process_health`, blocker reason, resumability,
  and remaining work when a later GitHub workflow-job event reports failure.
- Store the workflow conclusion separately as infrastructure observation
  metadata instead of replacing a healthy structured worker result.

## Compatibility, security, and known limitations

Serialized node usage accepts the legacy `model_calls` field as consumed usage.
No credential scope, repository permission, or provider-network access is
added. The coordinated RustGrid backend terminal-outcome contract must be
deployed before or with this worker release.

Artifact publication updates the GitHub release, native binaries, Homebrew
formula, SBOM, attestations, and container. It does not update the production
worker artifact pin automatically. Production must be configured with the
exact v1.4.24 Linux archive URL and SHA-256 after the protected release workflow
completes.

## Verification

The complete locked suite passes 432 unit tests, 14 API-contract tests, 10 CLI
tests, and 8 hosted-orchestrator replay tests. Formatting, strict Clippy, the
JavaScript wrapper suite, and the release build pass. Regression coverage
includes exact-boundary admission, concurrent reservation exclusion, provider
failure reconciliation, bootstrap allowances, authoritative post-plan budget
replacement, first discovery dispatch, and terminal worker-result precedence.

The coordinated RustGrid `ticket-service` suite passes all 386 tests, including
the `blocked_no_diff` workflow-observation regression.

## Rollback

Stop new hosted dispatches before restoring the RustGrid worker download URL
and SHA, canonical workflows, and Homebrew installations to v1.4.23. Do not
replace or mutate the v1.4.24 tag or release assets. Usage checkpoints remain
backward readable because legacy consumed-call fields are accepted.
