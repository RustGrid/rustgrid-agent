# rustgrid-agent v1.4.50

This patch release enforces an active mutation fallback policy at the actual
serialized provider-request boundary and preserves the known-good hosted
ticket-to-pull-request lifecycle as a permanent regression.

## Install or upgrade

On macOS with Homebrew:

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

For a new installation:

```sh
brew install RustGrid/tap/rustgrid-agent
```

## Fixed

- Preserve the selected `ForceReplaceFile` fallback decision through the
  existing implementation-to-repair transition until its provider call is
  serialized.
- Expose only `replace_file` in that provider request and use the existing
  named tool choice, making the excluded `apply_patch` tool unavailable.
- Keep normal mutation requests unchanged when no fallback policy is active.

## Regression coverage

- Capture the real `/ai/responses` payload after an initial patch failure and
  prove the fallback request contains only `replace_file`.
- Protect the generic hosted lifecycle from discovery and planning through the
  implementation barrier, focused and required validation, build, diff review,
  completion evaluation, commit, push, pull-request creation, and a healthy
  canonical terminal result.
- Prove missing terminal callback transport cannot overwrite the canonical
  successful or reviewable worker-domain outcome.

## Compatibility

No serialized contract, backend schema, graph architecture, budget, validation,
publication, or terminal-handling change is introduced. Deploy the RustGrid
backend compatibility change documented for v1.4.49 before pinning hosted
workers to v1.4.50.

After the protected release completes, pin the exact v1.4.50 Linux archive URL
and SHA-256 published by the workflow. Artifact publication does not update the
production backend variables automatically.

## Verification

The release candidate must pass formatting, strict Clippy, the full unit and
integration test suite, npm build, package verification, packaged-source
compilation, Homebrew formula syntax validation, and the version smoke test.

## Rollback

Stop new hosted dispatches before restoring the backend worker download URL,
checksum, container deployment, and Homebrew installations to v1.4.49. Do not
replace or mutate the v1.4.50 tag or release assets.
