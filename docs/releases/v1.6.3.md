# rustgrid-agent v1.6.3

This patch release makes IDE session timelines read as prompt, activity and
outcome, and makes linking a ticket look like it worked.

## Install or upgrade

```sh
brew update
brew upgrade RustGrid/tap/rustgrid-agent
```

Restart Claude Code after upgrading.

## Changed

- **Outcomes only.** For each prompt, the timeline keeps Claude's final reply,
  recorded as the turn's outcome when Claude Code reports the turn ended or the
  next prompt arrives. Interim narration ("Now let me check…") and read-only
  tool calls (Read, Grep, Glob, LS) are no longer posted; the activity steps
  already show that work. Commands, edits, pull requests and usage are
  unchanged.
- **Linking reads as success.** `/rustgrid-link ADD-123` no longer shows up as
  a blocked prompt. The hook links the session and tells Claude, which confirms
  it in one line. A link that fails still blocks, with the reason.
- **The `/rustgrid-link` command file** is rewritten when it is out of date.

## Compatibility

Works with the same RustGrid as v1.6.2. Sessions already in progress keep
their earlier events.

## Verification

The release candidate must pass formatting, strict Clippy, the full unit and
integration test suite, npm build, package verification, packaged-source
compilation, Homebrew formula syntax validation, and the version smoke test.

## Rollback

Reinstall v1.6.2. Do not replace or mutate the v1.6.3 tag or release assets.
